🤖 AI-Powered Learning Management System

An industry-grade AI-Powered Learning Management System (LMS) designed to provide students with an interactive platform for learning programming, artificial intelligence, machine learning, web development, Java, and database management.

🚀 Project Overview

The AI Learning Management System provides a simple and user-friendly learning environment where students can:

- 📚 Access multiple programming and technology courses
- 📝 Learn through structured lessons
- 📊 Track course progress
- 🤖 Interact with an AI Tutor
- 💻 Practice programming concepts
- 🧠 Take quizzes and check scores
- 🎯 Complete courses and monitor learning progress

✨ Features

👤 User Authentication

- Student Registration
- Student Login
- User-friendly authentication interface

📊 Student Dashboard

- View available courses
- Access enrolled courses
- Track learning progress
- Quick access to AI Tutor

⚙️ How to Run the Project

1. Clone the repository

git clone https://github.com/jmythri1234/AI_Learning_Management_System.git

2. Open the project

cd AI_Learning_Management_System

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

Windows PowerShell:

venv\Scripts\Activate.ps1

5. Install required packages

pip install flask

6. Run the application

python app.py

Then open the local URL shown in the terminal.
